# Changelog

## 1.0.1

- Added the public GitHub repository link to the package website and README.
- Published source code and packaged downloads on GitHub. Mod behavior is unchanged.

## 1.0.0

- Initial release.
- Voice tab in the player list (Tab) with a volume slider, value and reset button for every player.
- Volumes are saved per player (Steam ID) and re-applied when players join, rejoin or reconnect to voice chat.
- Mic icon shows who is talking and toggles the game's own voice mute.
- `MaxVolumePercent` and `DefaultVolumePercent` settings.
